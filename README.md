# Gemini Snap - Downloads

Screenshot your screen, get the answer from Google Gemini, shown in a small popup you can move.
Works on **macOS** and **Windows**.

## Get it

Open the **[Releases](../../releases)** page (or the link on the right side of this page) and
download the file for your system:

- **Mac, Apple Silicon** (M1/M2/M3/M4): `GeminiSnap-Mac-AppleSilicon.dmg`
- **Mac, Intel**: `GeminiSnap-Mac-Intel.dmg`
- **Windows**: `GeminiSnap-Setup.exe`

Each release also includes a plain `.zip` version of the same app, in case the installer doesn't
work on your machine.

## Setup

1. Install it like any normal app (Mac: drag into Applications from the `.dmg`; Windows: run the
   installer).
2. Get a **free** Gemini API key: https://aistudio.google.com/apikey
3. Open the app, click the circle in the menu bar (Mac) / system tray (Windows) ->
   **Set Gemini API Key...**, and paste it in.
4. Mac: allow **Screen Recording** for the app when asked (System Settings -> Privacy & Security),
   then reopen it.

## Shortcuts

| Action | Mac | Windows |
|---|---|---|
| Screenshot now and answer | ⌥⌘1 | Ctrl+Alt+1 |
| Add a screenshot to the batch | ⌥⌘3 | Ctrl+Alt+3 |
| Send the batch, all answers in a row | ⌥⌘4 | Ctrl+Alt+4 |
| Clear the batch | ⌥⌘5 | Ctrl+Alt+5 |
| Hide / show the popup | ⌥⌘2 | Ctrl+Alt+2 |

Drag the popup by its top strip to move it anywhere on screen. Answers are final answers only.

## First-run warning

The first time you open it, macOS / Windows will warn that it's from an unidentified developer.
That's the standard warning for any app outside the App Store / Microsoft Store, not a virus
report - click through it (Mac: right-click -> Open; Windows: More info -> Run anyway).
